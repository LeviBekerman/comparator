# עולם הלמידה 🎓

אתר למידה אינטראקטיבי לילדים - **פועל לגמרי במכשיר, ללא צורך בחיבור לאינטרנט**.

## איך פותחים
פשוט פותחים את `index.html` בדפדפן (לחיצה כפולה על הקובץ), או מריצים שרת מקומי פשוט:

```
cd kids-learning
python3 -m http.server 8080
```
ואז נכנסים ל- `http://localhost:8080`.

כל המידע (התקדמות, כוכבים, פרופילים) נשמר במכשיר עצמו (localStorage) - שום דבר לא נשלח לאינטרנט.

## מה יש באתר
- **עולם אותיות ומספרים** - אותיות א׳-ת׳, מספרים 1-20, ורמת ניקוד מתקדמת.
- **עולם כיתה ב׳** - חשבון (חיבור, חיסור, כפל, חילוק, בעיות מילוליות) ואנגלית (אלף-בית, צבעים, בעלי חיים, משפחה, מספרים, משפטים פשוטים).
- כל רמה בנויה משלושה שלבים: **שיעור קצר** עם הקראה קולית, **תרגול** עם משוב מיידי, ואז **משחק** (התאמת זוגות או תשובות מהירות).
- אפשר ליצור כמה פרופילים של ילדים, וההתקדמות (כוכבים ורמות פתוחות) נשמרת בנפרד לכל פרופיל.

## הערה על קול
ההקראה משתמשת במנוע הדיבור המובנה של הדפדפן/מערכת ההפעלה (Web Speech API). אם למכשיר יש קול עברי/אנגלי מותקן, ההקראה תעבוד גם ללא אינטרנט. אם אין קול זמין, האתר ימשיך לעבוד מצוין גם בלי קול - כל התוכן מוצג גם בטקסט ובתמונות.
